# Definition of Done

A feature is complete only when all of the following are true:
- The user need is traceable to an implemented requirement.
- The acceptance criteria are met and validated.
- Authorization and validation states are correct.
- Security and privacy controls are considered and documented.
- Responsive UI and accessibility requirements are verified where applicable.
- The relevant tests are written and actually executed.
- Linting, type-checking, and build checks pass for the affected area.
- Documentation is updated when the behavior changes.
- No known blocker remains that would materially affect safety, trust, or operability.

## Release Readiness
A release candidate is ready when critical flows have passed validation, the environment is configured, and the operational runbook and monitoring checks are in place.
