# ADR Index

This directory records significant architectural decisions for Smart Agenda.

## Current ADRs
- ADR-001: Modular monolith for MVP
- ADR-002: Relational database as the system of record
- ADR-003: Notification abstraction for email, SMS, and WhatsApp
- ADR-004: Provider-first integration strategy with sandbox support
- ADR-005: Privacy-first guest access model

## How to add an ADR
1. Draft the problem and decision clearly.
2. Capture background choices, consequences, and alternatives.
3. Link the ADR from the architecture and decisions log docs.
4. Keep the ADR concise and decision-oriented.
