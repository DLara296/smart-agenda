# ADR Contribution Guide

This folder captures significant architecture decisions for the Smart Agenda project.

## Expected format
- Title: short and decision-oriented
- Status: proposed, accepted, superseded
- Context: problem or background
- Decision: chosen approach
- Consequences: trade-offs and follow-up actions

## Review expectations
- Keep the ADR focused on one major decision.
- Link to requirements and project goals when relevant.
- Include the owner or team decision path if known.
